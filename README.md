# Revela — filtros de cor no iPhone

App web (abre no Safari, instala na Tela de Início). Aplica LUTs (.cube) e ajustes de cor em fotos, tudo no próprio aparelho — nada é enviado pra lugar nenhum.

- Filtros prontos: Fuji NYC, Fuji suave, Fuji filme, Tarde, P&B
- Ajustes: exposição, contraste, realces, sombras, temperatura, tonalidade, saturação, vibração, desbotar, granulado, vinheta
- Salvar seus próprios filtros e importar qualquer `.cube`
- Várias fotos de uma vez; salva pelo menu de compartilhar → "Salvar imagens"
